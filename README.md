# Fake News Detection System

A machine learning project that uses Natural Language Processing (NLP) and TF-IDF to classify news articles as **Fake** or **Real**.

## Features
- Text preprocessing and feature extraction using TF-IDF.
- Trained and compared four machine learning models.
- Evaluated models using accuracy, precision, recall, and F1-score.

## Models & Accuracy
- Logistic Regression: 94%
- Decision Tree: 88%
- SVM: **96%**
- Random Forest: 90%

## Technologies Used
- Python
- Machine Learning
- NLP
- Scikit-learn
- Pandas
- NumPy

## Key Result
Achieved **96% accuracy** using Support Vector Machine (SVM).
